# טוי באק — אתר חנות רב־מחלקתית

אתר סטטי, בלי שלב בנייה ובלי תלויות להתקנה. מעלים את התיקייה כמו שהיא ומפעילים GitHub Pages.

## העלאה לגיטהאב

1. יוצרים מאגר חדש, ציבורי.
2. מעלים את כל הקבצים לשורש המאגר. כולם שטוחים, אין תיקיות, ולכן אפשר לגרור את כולם יחד.
3. במאגר: Settings, ואז Pages.
4. תחת Source בוחרים Deploy from a branch, הענף main והתיקייה root.
5. שומרים. תוך דקה עד שתיים האתר עולה בכתובת שמופיעה שם.

לדומיין משלך: מוסיפים במאגר קובץ בשם CNAME שבתוכו שורה אחת עם הדומיין, ומפנים אצל רשם הדומיין רשומת CNAME אל הכתובת של גיטהאב.

## מבנה הקבצים

כל הקבצים יושבים בשורש המאגר, בלי תיקיות.

- index.html — חזית החנות
- admin.html — פאנל הניהול
- catalog.js — כל התוכן: מחלקות, מוצרים, מחירים, תמונות ופרטי העסק
- styles.css — טוקני העיצוב וכל הסגנונות
- store.js — שכבת הנתונים והעזרים
- motion.js — הגיבור בקנבס, הרצועה, החשיפות וצמצום התנועה
- app.js — הרכבת החזית
- admin.js — הפאנל
- favicon.svg, robots.txt, .nojekyll, .gitignore

## איך מעדכנים תוכן

הפאנל שומר במכשיר שלך בלבד, ולכן עריכה בו לא משנה את מה שהמבקרים רואים. תהליך הפרסום:

1. פותחים את admin.html ועורכים.
2. לוחצים על "ייצוא קובץ אתר". יורד קובץ בשם catalog.js.
3. מחליפים בו בגיטהאב את catalog.js.
4. גיטהאב מפרסם מחדש לבד.

הכפתור "ייצוא גיבוי" מייצר קובץ JSON להעברת התוכן בין מכשירים, דרך "ייבוא גיבוי".

## הערה על התמונות

התמונות מקושרות לשרת של וולט ולא הועתקו למאגר. הן מתעדכנות לבד, אבל יישברו אם וולט תסיר אותן. אם רוצים עצמאות מלאה, מורידים אותן למאגר ומחליפים את הכתובות בקובץ catalog.js.

## שתי התבניות

השדה restricted בהגדרת המחלקה קובע את התצוגה.

מחלקה רגילה מקבלת רשת כרטיסים עם תמונה, תיאור, מחיר, מחיר קודם, זמינות והנפשת ריחוף.

מחלקת מוצרי טבק או עישון מקבלת רשימה טקסטואלית של שם, מחיר וזמינות, בלי אנימציה, בלי תגי מבצע ובלי דירוגים. בראש המחלקה אזהרה סטטוטורית בבלוק גדול, ובכניסה לאתר שער אישור גיל.

שדה התמונה, הטקסט החלופי והתיאור קיימים בכל מוצר בכל מחלקה ונשמרים תמיד. ההצגה בפועל נשלטת בשני מתגים בהגדרות המחלקה. בקטלוג הנוכחי הם דולקים בכל המחלקות, לפי הנחיית בעל העסק.

## נגישות

קישור דילוג לתוכן, ניווט מלא במקלדת בין הלשוניות, מיקוד גלוי, ניגודיות טקסט של 4.5 ומעלה, וטקסט חלופי חובה כשמזינים תמונה.

צמצום התנועה בנוי כמסלול ראשי: כשהמשתמש ביקש זאת במערכת ההפעלה, או לחץ על המתג שבפינת המסך, אין גלילה חלקה, אין לולאת ציור, והקנבס מצויר פעם אחת במצבו המסודר.

## מצב הקטלוג

נאספו שלוש קטגוריות מתוך עשרים וארבע שבדף העסק בוולט: טבק, סיגריות ומצתים. סך הכול 103 מוצרים.

טרם נאספו: סיגריות אלקטרוניות, סיגרים וסיגרלות, מכשירים לאייקוס ואידוי, מצית זיפו, מוצרי עישון, אביזרי עישון, מוצרי אחסון, קוצצים, נרגילות ואביזרים, תחליפי טבק ללא ניקוטין, סנוסים ופאוץ ניקוטין, טבק למקטרת, טבק לנרגילה, טבק הרחה, פייפים ומקטרות, כדים, מבחנות, ביגוד ואביזרים, צעצועים ומשחקים, שתייה קרה, ממתקי גומי.

בקטגוריית הסיגריות יש עמוד נוסף מעבר לחמישים הפריטים שנאספו.

## מה עדיין דורש שרת

1. הזדהות אמיתית לפאנל. בדיקת סיסמה בדפדפן אינה הגנה, ולכן admin.html נגיש לכל מי שיודע את הכתובת. הקובץ robots.txt מבקש ממנועי החיפוש לא לאנדקס אותו, וזו בקשה ולא חסימה.
2. סליקה. פרטי כרטיס חייבים לעבור ישירות לספק מורשה בעמוד מתארח או במסגרת מוטמעת, ומפתח סודי לעולם אינו בקוד שרץ בדפדפן.
3. מלאי בזמן אמת מול הקופה.

עד אז ההזמנות עוברות בוואטסאפ, וזה מסלול לגיטימי ומלא.

## לפני העלייה לאוויר

הטקסטים המשפטיים בפאנל הם טיוטות שלד ואינם ייעוץ משפטי. יש למלא את שם העוסק, מספר העוסק ורכז הנגישות, ולהעביר את האתר ואת התקנון לבדיקת עורך דין המתמצא ברגולציית טבק ובדיני מסחר מקוון.
